2. User Registration Sequence Flow

Input validation, CSRF verification, password hashing with cost 12, MySQL insertion, and MongoDB profile initialization.

sequenceDiagram autonumber actor User as User Browser participant JS as js/register.js participant PHP as php/register.php participant MySQL as MySQL (nura_auth) participant Mongo as MongoDB (nura_profiles) User->>JS: Submit Registration Form JS->>PHP: AJAX POST /php/register.php (with X-CSRF-Token) PHP->>PHP: Validate Inputs & CSRF Token PHP->>MySQL: SELECT id FROM users WHERE username = ? OR email = ? alt User Already Exists MySQL-->>PHP: Found Match PHP-->>JS: HTTP 409 Conflict else Account Is New MySQL-->>PHP: No Record PHP->>PHP: password_hash(pwd, PASSWORD_DEFAULT, cost=12) PHP->>MySQL: INSERT INTO users (username, email, password_hash) MySQL-->>PHP: lastInsertId PHP->>Mongo: insertOne(initial_profile) PHP-->>JS: HTTP 201 Created JS-->>User: Redirect to login.html end

3. User Authentication & Login Sequence Flow

Credential verification, session rotation, in-memory Redis session creation, and secure HttpOnly cookie assignment.

sequenceDiagram autonumber actor User as User Browser participant JS as js/login.js participant PHP as php/login.php participant MySQL as MySQL (nura_auth) participant Redis as Redis Cache User->>JS: Submit Credentials JS->>PHP: AJAX POST /php/login.php (with X-CSRF-Token) PHP->>PHP: Validate CSRF Token PHP->>MySQL: SELECT id, password_hash FROM users WHERE identifier MySQL-->>PHP: User Row alt Invalid Password PHP->>PHP: password_verify() fails PHP-->>JS: HTTP 401 Unauthorized else Valid Password PHP->>PHP: destroy_auth_session() [Session Rotation] PHP->>PHP: Generate 256-bit Random Token PHP->>Redis: SETEX auth_session:{token} 3600 (Payload) Redis-->>PHP: OK PHP->>PHP: Set-Cookie: nura_auth_session (HttpOnly, SameSite=Lax) PHP-->>JS: HTTP 200 OK (User Metadata) JS-->>User: Redirect to profile.html end

4. Authenticated Profile Retrieval & Update Flow

Redis session validation, MongoDB profile query, XSS sanitization, and profile upsert.

sequenceDiagram autonumber actor User as User Browser participant JS as js/profile.js participant PHP as php/profile.php participant Redis as Redis Cache participant Mongo as MongoDB (nura_profiles) Note over User, Mongo: Profile Retrieval (GET) JS->>PHP: AJAX GET /php/profile.php (Cookie attached) PHP->>Redis: GET auth_session:{cookieToken} alt Expired or Invalid Session Redis-->>PHP: Null PHP-->>JS: HTTP 401 Unauthorized JS-->>User: Redirect to login.html else Valid Session Redis-->>PHP: Session Payload (user_id) PHP->>Mongo: findOne({ user_id }) Mongo-->>PHP: Profile Document PHP-->>JS: HTTP 200 OK (Safe Profile JSON) JS-->>User: Render Profile Console end Note over User, Mongo: Profile Update (POST) User->>JS: Submit Profile Changes JS->>PHP: AJAX POST /php/profile.php (Payload + X-CSRF-Token) PHP->>PHP: Verify CSRF & Validate Inputs PHP->>Mongo: updateOne({ user_id }, { $set: updateFields }, { upsert: true }) Mongo-->>PHP: OK PHP-->>JS: HTTP 200 OK JS-->>User: Update Display in Real Time

5. Session Invalidation & Logout Sequence Flow

Redis key deletion and authentication cookie expiration.

sequenceDiagram autonumber actor User as User Browser participant JS as js/profile.js participant PHP as php/logout.php participant Redis as Redis Cache User->>JS: Clicks Sign Out JS->>PHP: AJAX POST /php/logout.php (with X-CSRF-Token) PHP->>PHP: Validate CSRF Token PHP->>Redis: DEL auth_session:{cookieToken} Redis-->>PHP: Key Deleted PHP->>PHP: Set-Cookie: nura_auth_session (Expired in past) PHP-->>JS: HTTP 200 OK JS-->>User: Redirect to login.html?logout=true
